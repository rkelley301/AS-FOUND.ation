# AS-FOUND.ation

An interactive field learning system for industrial instrumentation.
Standalone HTML modules — open `index.html` in any browser. No server, no build step;
works offline (Google Fonts load when online).

Every module follows the same six sections: Hook · Analogy · Core Concepts ·
Hands-On Exercise · Quick-Check Quiz · Cheat Sheet Card.

- **Foundation Layer (F1–F5):** DC circuits, terminations, wiring diagrams,
  terminal boards and cabinets, PLC ↔ instrument signal flow.
- **Main Content Layer (M1–M6):** M1 PID Loop Control, M2 Control Valves & Final
  Control Elements. M3–M6 (calibration, networks, measurement, electrical & motor
  controls) are pending.
